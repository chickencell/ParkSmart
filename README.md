# ParkSmart: College Parking Finder

CSCI 4250 Human-Computer Interaction, Fall 2026, Nicholas Palmgren

ParkSmart is a mobile-friendly app that helps students find an open parking lot
near the campus building they're going to. It shows campus lots on a map,
colored by availability, and suggests the closest lots that still have open spots.
Availability is simulated for the prototype.

## What's in this repository

| Folder | What it is |
|---|---|
| [`tutorial-leaflet/`](tutorial-leaflet/) | **Milestone 1 tutorial code.** Code from the official Leaflet Quick Start and Leaflet on Mobile tutorials. Its README explains where the code came from. |
| [`parksmart-app/`](parksmart-app/) | Early ParkSmart prototype (4 screens: Campus Map, Find a Building, Best Lots, Lot Info), built with Leaflet. |
| [`m2-prototype/`](m2-prototype/) | **Milestone 2 runnable prototype.** Clickable version of the refined sketches (open `index.html`). |
| [`docs/`](docs/) | Milestone 1 lo-fi prototype (PDF and PowerPoint) and the Milestone 2 writeup (Word and PDF). |

## Running the code

No install needed. Open any `index.html` file in a web browser while connected to
the internet (Leaflet and the map tiles load online).
